# AI-use register

## AI inside the product

MigrationHelp calls the Google Gemini API. Gemini receives the user's question
and a small set of reviewed official facts, then returns structured JSON with a
short route. Normal Python code performs input checks, selects sources,
validates fields and source IDs, handles failure, and controls what is shown.

## AI used during development

Codex assisted with code review, test suggestions, documentation wording and
presentation editing. Maximilian remains responsible for the final submission,
ran the tests, checked the evidence, and must be able to explain and change the
code without reading generated text.

AI assistance is disclosed here; it is not evidence of student understanding.
No API key or user data is included in the repository.
