## Hackathon 2 redo: Flow State

Flow State is a capacity-aware study planner built in n8n. OpenAI extracts tasks and deadlines from a student's free-form text. JavaScript validates the output, calculates available focus time, and creates a seven-day plan without silently exceeding the student's capacity.

The complete redo is in [`hackathon/`](hackathon/):

- [Project README](hackathon/README.md)
- [Ethical reflection](hackathon/ETHICAL_REFLECTION.md)
- [Importable n8n workflow](hackathon/Flow-State-n8n-Workflow.json)
- [Presentation](hackathon/Flow-State-Presentation.pptx)
- [Narrated demo](hackathon/Flow-State-Demo.mp4)
