# Week 7 photo folder

This folder contains 10 PNG photos taken by Max before running
`../Week7_Object_Recognition_Resit.ipynb` in Colab: five normal one-bottle
photos, three zero-bottle controls and two difficult one-bottle photos.

The difficult cases use low light and partial occlusion. The images contain no
recognisable people and were visually checked before being added to the public
portfolio.
