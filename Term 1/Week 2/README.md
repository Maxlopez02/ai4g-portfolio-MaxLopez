# Term 1, Week 2

## Hackathon 2 resit: Flow State

Flow State is a capacity-aware study planner built in n8n for adult HBO and WO students. A student enters assignments, deadlines and available study time. OpenAI converts the unstructured task description into structured data. JavaScript then validates the AI output and builds a seven-day plan without exceeding the student's calculated focus capacity.

The project supports SDG 3 by addressing one concrete contributor to student stress: workloads that cannot fit before their deadlines. It is a planning aid, not a mental-health assessment or clinical service.
