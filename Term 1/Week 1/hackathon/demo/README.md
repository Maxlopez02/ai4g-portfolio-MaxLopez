# Prompt Coach demo

[Watch the 41-second screen recording](prompt-coach-screen-demo.webm)

![Animated Prompt Coach walkthrough](prompt-coach-demo.gif)

The screen recording captures the complete example flow in the connected Lovable preview on 10 September 2026. It shows the real interface actions and live AI responses:

1. The learner enters “Understand Python while loops” and the draft “Help me learn Python.”
2. The live Lovable AI service evaluates Goal, Context, Constraints and Output and returns feedback about the submitted wording.
3. The learner revises the prompt. The live service compares both versions and returns specific improvements plus one next step.

The animated GIF provides a quick overview, while the WebM file is the full browser recording. The three JPEG files provide still evidence for each stage. All of them show the working product, not wireframes or a static design mock-up. The product source and server-side Lovable AI integration are in [`../prompt-coach/`](../prompt-coach/).
