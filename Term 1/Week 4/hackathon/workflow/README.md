# ComfyUI workflow exports

This directory contains the two linked workflow stages used for the project:

- `text-to-image.json` — produces the fixed-window key frames with SDXL and ControlNet.
- `image-to-video.json` — animates an approved frame with the MiniMax H3 image-to-video pipeline.

Open each file in ComfyUI and install any model files or custom nodes reported as missing. The files were retrieved from the project partner's Week 4 portfolio repository and validated as readable JSON exports.
